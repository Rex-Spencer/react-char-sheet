# React Character Sheet:

## Description:

The React Character Sheet is a React app hosted via GitHub pages that aims to provide a simple, and easily usable online character sheet for D&D players to use.

## Getting Started:

To begin using the React Character Sheet, simply follow this [link](https://rex-spencer.github.io/react-char-sheet/)

## Known Issues, and Future Improvements:

### Known Issues:

There are currently no known issues.

## Version History:

- 0.1.0
    - General Changes:
        - Added Main Page which features the following sections: Character Identification, Character Vitals, Character Stats, Character Equipment, and Character Features.
        - Added automatic Proficiency Bonus modification based on Level selected.
        - Added automatic population of Skills modifiers when Stat Scores are filled in.
        - Added support to add Proficiency and Expertise to Skills via checkboxes found beside each Skill. Clicking the first check box will add the Proficiency Bonus to the Skill, and the second will double it.
        - Added ability to add and remove rows from the Attacks & Spellcasting subsection via corresponding buttons.
    - Bug Fixes:
        - No bugs were fixed in this release.
